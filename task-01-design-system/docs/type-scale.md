Display/headline use 1.4 for short headings. Titles use 1.5 for order summaries. Body uses 1.6 to separate wrapping progress updates. Labels use 1.4 within controls; touch-target padding remains separate. Body Small and Label Small are for secondary metadata, not important delivery dates or balances.

Use Display for short introductory text, Headline for pages, Title for order cards, Body for explanations and Label for buttons. Do not use Display Large on narrow phones without responsive sizing.
