# Deliberate Failure 1: The Nested Folder / Working Directory Mismatch
Evidence File: evidence/05-nested-folder-error.txt
Date: 2026-10-31 (Verified & Documented: 2026-11-01)

## Context & Cause
AI coding agents frequently scaffold into a redundant nested subfolder (e.g. creating `app/app/` or placing code in a nested subdirectory rather than directly in the target directory). When startup commands (`node src/server.js` or `npm start`) are executed from the intended project directory, Node cannot find the entry point, and npm cannot locate `package.json`.
