# Recovery 1: Fixing the Nested Folder Error (Both Ways)
Evidence File: evidence/06-nested-folder-fixed.txt
Date: 2026-10-31 (Verified & Documented: 2026-11-01)

Per the assessment instructions (*"fix it both ways: by telling the agent to rescaffold in place, and by changing directory. Submit both."*), we demonstrate both true recovery paths from an isolated test reproduction.

---

## Fix Method 1: Changing Directory (`cd`)

The immediate manual workaround when files reside in a nested subfolder: change working directory into the nested folder before executing startup commands.

### Terminal Commands and Successful Output:
```text
$ cd /tmp/nested-folder-experiment/app
$ cd app
$ pwd
/tmp/nested-folder-experiment/app/app

$ npm start
npm notice run nits-cut-portal@0.1.0 start
npm notice run node src/server.js
[Nit's Cut Server] Process 71768 started cleanly from /private/tmp/nested-folder-experiment/app/app
```

---

## Fix Method 2: Actual Rescaffolding / Flattening in Place

When preserving the intended project root location so that scripts run directly from the parent directory without navigating into a redundant subfolder, we instruct the agent to flatten/rescaffold the structure in place.

### The Agent Prompt Used for Rescaffolding:
> *"You scaffolded the application into an accidental nested directory (`app/app/`), causing `MODULE_NOT_FOUND` and `ENOENT` when commands run from `app/`. Move all contents of `app/app/` up to `app/`, update any relative file imports and paths, remove the empty nested directory, and verify that `npm start` executes cleanly in place directly from `app/`."*

### Execution of In-Place Restructuring & Clean Startup:
```text
$ cd /tmp/nested-folder-experiment/app
$ mv app/* .
$ rmdir app
$ ls -la
total 8
drwxr-xr-x  4 blk  wheel  128 Nov  1 05:16 .
drwxr-xr-x  3 blk  wheel   96 Nov  1 05:16 ..
-rw-r--r--  1 blk  wheel  128 Nov  1 05:16 package.json
drwxr-xr-x  3 blk  wheel   96 Nov  1 05:16 src

$ npm start
npm notice run nits-cut-portal@0.1.0 start
npm notice run node src/server.js
[Nit's Cut Server] Process 71803 started cleanly from /private/tmp/nested-folder-experiment/app
```
