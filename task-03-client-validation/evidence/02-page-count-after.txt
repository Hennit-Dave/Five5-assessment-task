HOW PAGES ARE COUNTED (identical rule to 01-page-count-before.txt)
  A user-facing page is a distinct URL path that answers an HTTP GET with status 200 and a
  text/html document meant for a person to read.
  - Query-string variants of one path (e.g. /auth?mode=login and /auth?mode=reset) count as ONE page.
  - Redirects (such as /auth -> /auth?mode=login), the 404 page, POST-only endpoints (POST /inquiries)
    and static assets are not counted.
  Tool: task-03-client-validation/scripts/page-inventory.mjs (probes candidate list over HTTP).
