3. SESSION RESULT EXPLANATION
Question: Did switching forms create a new session?
Answer: No.
Detailed explanation:
1. Session handling is not implemented in this application yet.
   Inspection of `app/src/server.js` and `package.json` confirms that neither `express-session`,
   cookie parsing, nor any other session middleware exists. All incoming HTTP requests are stateless.
2. Even if session middleware were configured, because switching between forms happens entirely
   in the browser via DOM manipulation and `history.pushState` (zero HTTP requests are sent to the server),
   the server has no opportunity or reason to create, touch, or renew a session during form switching.
