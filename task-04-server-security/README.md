- **Step 9 — Breached Password Checks:**
  - **k-Anonymity Hash-Prefix Implementation:** Created `app/src/breachCheck.js` integrating the Have I Been Pwned API v3 range model. Transmits only 5-character SHA-1 prefixes over HTTPS with `Add-Padding: true`. Suffix matching (35 hex chars) occurs strictly in local memory; padding dummy entries (`count === 0`) are ignored.
  - **Lifecycle Ordering & Protection:** Placed check in `POST /auth/signup` strictly after Zod schema validation (zero network calls for malformed inputs) and strictly before Argon2id hashing and database writes (protecting 64 MiB RAM and CPU cycles from exhaustion when breached passwords are submitted). Routine login and reset routes do not call this service.
  - **Three Explicit Outcomes & Bounded Timeout:** Enforces `breached`, `not_found`, and `unavailable`. Both connection and response-body streaming are bound by a 2,000 ms timeout. Failures are never collapsed into `not_found`.
  - **Strict Response Validation:** Accepts only HTTP 200, strictly validates every non-empty line (35-hex suffix and complete non-negative integer count), rejects permissive parsing (e.g. "0garbage", decimals, negatives), and treats any malformed line as failing the entire response while permitting normal trailing blank lines.
  - **Fail-Closed Availability Trade-off:** Implemented fail-closed policy as our chosen project policy: returns `HTTP 503 Service Unavailable`, renders plain customer retry message, and creates zero accounts. Documented the trade-off (strict compliance vs hard third-party availability dependency) in [`docs/breach-check.md`](docs/breach-check.md).
  - **Confidentiality & Zero Credential Logging:** Strictly bans logging passwords, full hashes, suffixes, prefixes, or URLs with prefixes. Logs only duration, outcome, and error category. Distinguished fictional test fixtures in evidence from operational logs.
  - **Live Verification & Visual Evidence:** Verified live-confirmed breached password `"password12345678"` (16 chars, count 24,881 at test time) and multi-word passphrase `"correcthorsebatterystaple"` (25 chars, count 4,173).
